# VE Builder Card 1.0.2

## English

The card picker now shows a vehicle illustration, sample metrics and charging preview instead of an empty card. Sample data is explicitly labelled and has no controls. Configured cards are unchanged. The legacy vehicle-builder-card-v1 picker entry is hidden; its component remains usable for existing backups.

## Español

El selector muestra una ilustración de vehículo, métricas de ejemplo y carga en lugar de una tarjeta vacía. Los datos están identificados como ejemplo y no tienen controles. Las tarjetas configuradas se conservan. Se oculta la entrada vehicle-builder-card-v1 del selector, manteniendo el componente para las copias existentes.
