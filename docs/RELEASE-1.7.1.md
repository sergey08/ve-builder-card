# VE Builder Card 1.7.1

## English

- Generic block types in Add block, each with a short description: Overview with image, Data and sensors, Selection buttons, Charging power, Slider controls, Action buttons, Location map, Costs and savings, and Vehicle status.
- New blocks start empty; configure their title, entities and appearance without copying another block's data.
- Optional OTA version and update-status sensors in Overview with image. The OS/version appears to the right of the vehicle title, with an amber exclamation icon when an update is confirmed.
- Leave the version sensor empty, or without a usable reading, to hide the version indicator.
- Editor labels and help in English, Spanish, Portuguese, French, German, Italian and Dutch.
- Existing cards and entity assignments remain compatible.

Stable release published on 29 October 2026. This documentation update corrects obsolete beta labels; it does not change the card code or distributed JavaScript.

## Español

- Tipos genéricos en Añadir bloque, cada uno con una descripción breve: Inicio con imagen, Datos y sensores, Botones de selección, Potencia de carga, Controles deslizantes, Botones de acciones, Mapa de ubicación, Gastos y ahorro y Estado del vehículo.
- Los bloques nuevos empiezan vacíos; configura título, entidades y presentación sin copiar datos de otro bloque.
- Sensores opcionales de versión OTA y estado de actualización en Inicio con imagen. El sistema y su versión aparecen a la derecha del título, con una exclamación ámbar cuando se confirma una actualización.
- Si el sensor de versión está vacío o no tiene una lectura válida, se oculta el indicador.
- Editor y ayuda en inglés, español, portugués, francés, alemán, italiano y neerlandés.
- Se conserva la compatibilidad de las tarjetas y entidades existentes.

Versión estable publicada el 29 de octubre de 2026. Esta actualización de documentación corrige etiquetas antiguas de beta; no cambia el código de la tarjeta ni el JavaScript distribuido.
