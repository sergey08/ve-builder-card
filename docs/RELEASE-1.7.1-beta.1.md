# VE Builder Card 1.7.1-beta.1

## English

- Add block now uses explicit generic types: Overview with image, Data and sensors, Selection buttons, Charging power, Slider controls, Action buttons, Location map, Costs and savings, and Vehicle status.
- New blocks start empty. Configure their title and entities afterwards; existing blocks and entity assignments remain unchanged.
- Each type has a brief description that updates when selected.
- Clarifying help and labels in all seven interface languages.

## Español

- Añadir bloque muestra tipos genéricos explícitos: Inicio con imagen, Datos y sensores, Botones de selección, Potencia de carga, Controles deslizantes, Botones de acciones, Mapa de ubicación, Gastos y ahorro y Estado del vehículo.
- Los bloques nuevos empiezan vacíos. Después configura título y entidades; se conservan los bloques existentes y sus entidades.
- Cada tipo incluye una descripción breve que cambia al seleccionarlo.
- Etiquetas y ayuda en los siete idiomas de la interfaz.
