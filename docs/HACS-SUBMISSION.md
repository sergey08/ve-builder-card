## Description

Adds `sergey08/ve-builder-card` to the plugin list in alphabetical order.

VE Builder Card is a configurable vehicle dashboard card with a visual block editor, charging information and controls, a vehicle diagram with tyre pressures and opening indicators, location, costs and optional alert summaries.
