# VE Builder Card 1.0.0-rc.1

## English

First release candidate for VE Builder Card 1.0. Visual block editor, starter templates, drag ordering, undo/redo, device filtering, English/Spanish interface, charging display, costs, maps and vehicle body/tyre diagram.

Existing custom:ve-builder-card configurations remain compatible. Vehicle entities and images are configured by each user.

Automated validation: 20 tests and a self-contained bundle build. The card is installed through HACS main and used in the maintainer’s dashboard; installation and upgrade from a numbered release still need validation.

Before stable 1.0.0: verify drag/save/reopen, undo/redo, device filtering, mobile and dark theme, open body parts, active charging and missing sensors in Home Assistant. This is a prerelease, not the stable 1.0.0.

HACS: add sergey08/ve-builder-card as a custom Dashboard repository. Enable prerelease/beta versions if required to select v1.0.0-rc.1, download, then reload the browser. No Home Assistant restart is needed for this frontend card.

## Español

Primera candidata a VE Builder Card 1.0. Editor visual por bloques, plantillas iniciales, ordenación arrastrando, deshacer/rehacer, filtro por dispositivo, interfaz español/inglés, carga, gastos, mapas y dibujo de carrocería/neumáticos.

Las configuraciones custom:ve-builder-card existentes siguen siendo compatibles. Cada usuario configura sus entidades e imágenes.

Validación automática: 20 pruebas y compilación autocontenida. La tarjeta está instalada desde main mediante HACS y se usa en el panel del mantenedor; queda validar la instalación y actualización desde una release numerada.

Antes de 1.0.0 estable: comprobar arrastrar/guardar/reabrir, deshacer/rehacer, filtro por dispositivo, móvil y tema oscuro, elementos abiertos, carga activa y sensores sin datos en Home Assistant. Es una versión previa, no la 1.0.0 estable.

HACS: añade sergey08/ve-builder-card como repositorio personalizado Dashboard. Activa versiones beta/previas si es necesario para seleccionar v1.0.0-rc.1, descarga y recarga el navegador. Esta tarjeta de interfaz no requiere reiniciar Home Assistant.
